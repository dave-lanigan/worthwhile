# Worthwhile Design System

## Visual World

Worthwhile is a private financial planning desk. It uses a pale mineral ground for context and a deep blue-green forecast field for analysis. The page should feel like an active statement: position first, forecast second, ledger as evidence.

## Color

- Ground: `#edf0eb`
- Ink: `#102831`
- Growth: `#79d2af`
- Neutral data: `#afc7d1`
- Liability: `#ec9f86`
- Divider: `#b9c5bd`

Use green for financial growth and rust for liabilities or warnings. The deep forecast field carries analytical focus; other regions remain quiet and unboxed.

## Typography And Layout

Use Manrope for headings and Public Sans for interface text. Figures use tabular numerals. Work surfaces use thin dividers, compact uppercase labels, small radii, and open whitespace instead of repeated cards. Desktop groups related position values in a strip; mobile stacks them as a statement.

## Components And Motion

The forecast is the singular dominant field. Deterministic and Monte Carlo states share the same chart stage; switching modes changes the chart to probability bands while retaining the reference line. Controls are compact and appear only when relevant. Interactions use brief color and surface transitions, with reduced motion fully respected.
